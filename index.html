#

Sorteador de Números

Como funciona

Sorteios rápidos, justos e sem complicação

Use o sorteador para rifas, brincadeiras, escolha de vencedores ou qualquer situação em que você precise de números aleatórios.

  1. Defina a quantidade Quantos números você quer sortear de uma vez.
  2. Escolha o intervalo Informe o menor e o maior número possíveis. Os dois entram no sorteio.
  3. Decida sobre repetições Marque “Não repetir número” para que cada número saia só uma vez.
  4. Clique em Sortear Os números aparecem logo abaixo. Pode sortear de novo quantas vezes quiser.
